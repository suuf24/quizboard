# Anti Slop Audit 002 - QuizBoard

- Tanggal: 2026-09-16
- Tindak lanjut dari: `anti-slop/audit-001-2026-09-16.md`
- Disetujui pemilik: **F-01, F-02, F-03, F-04, F-05, F-13**, ditambah tiga quick win (persistensi sesi,
  pengiriman tahap murah, kunci jawaban cetak)
- Metode bukti: pembacaan ulang source, `npm run lint`, `npm run build`, dan uji runtime di dev server
  (http://localhost:5175) lewat DevTools protocol: klik nyata, tombol keyboard yang diinjeksi ke main
  world, pembacaan DOM dan computed style. Viewport uji 440x688 (di bawah breakpoint 600px, jadi
  layout mobile aktif).

## Status yang disetujui

### F-01, em dash (R-02) - FIXED
- `src/App.tsx`: catatan shuffle memakai titik dua, strip jawaban preview memakai `B. Paru-paru`.
- Bukti: `grep -rn "—" src/` tidak menemukan satu pun hasil.

### F-02, Escape tidak menutup dialog keluar (R-32) - FIXED
- Handler keyboard presentasi disusun bertingkat: dialog keluar, lalu panel kunci jawaban, baru
  shortcut normal. Escape tidak pernah membuka lapisan baru di atas lapisan yang terbuka.
- Bukti runtime: Escape membuka dialog (`role="dialog"`, `aria-modal="true"`, `aria-labelledby="exit-dialog-title"`,
  fokus pindah ke tombol Cancel), Escape kedua menutupnya dan fokus kembali ke tombol `✕`
  (`aria-label="Exit presentation"`).

### F-03, panel Answer Key tanpa semantik dan Escape yang menumpuk dialog (R-32) - FIXED
- Panel kini `role="dialog"`, `aria-modal="true"`, `aria-labelledby="answer-key-title"`, fokus awal ke
  tombol tutup, Escape menutup panel, dan fokus kembali ke tombol 🔑. Selain itu ada tombol "🖨 Cetak"

- Perubahan perilaku yang perlu diketahui: selama panel terbuka, shortcut `N` dan `Spasi` tidak lagi
  menembus ke presentasi di belakangnya.
- Bukti runtime: panel terbuka dengan 22 baris dan dua tombol header, fokus di "Close answer key";
  Escape menutup panel, `document.querySelector('.dialog')` tetap kosong, fokus kembali ke
  `aria-label="Show answer key"`.

### F-04, kontras teks hint drop zone (R-25) - FIXED
- `.drop-zone__or` dan `.drop-zone__hint` pindah ke `--md-sys-color-on-surface-variant`. Rasio
  terhitung: 7,2:1 di latar normal, 6,19:1 di latar hover `primary-container` (sebelumnya 3,89:1).
- Alasan dan angkanya ditulis sebagai komentar tepat di atas aturan itu supaya tidak dikembalikan.

### F-05, tap target dan overflow bar kontrol (R-03) - FIXED
- `.control-btn` jadi 44x44 (terukur di runtime: enam tombol 44px).
- Di bawah 600px bar jadi dua baris: `flex-direction: column`, grup dirapatkan ke tengah,
  `.control-label` disembunyikan.
- Bukti runtime di viewport 440px: `flex-direction: column`, label `display: none`,
  `clientWidth === scrollWidth === 440` (tidak ada overflow), baris terlebar (grup 4 tombol) 188px.
  Pada viewport 360px, baris terlebar plus padding 24px menjadi 212px, masih di bawah 360px.

### F-13, pause tanpa umpan balik (C-2, R-27) - FIXED
- `.pause-overlay` (CSS-nya sudah ada sejak dulu) kini dirender: ikon ⏸, "Dijeda", "Tekan Spasi atau
  tombol di bawah untuk melanjutkan", dan tombol `▶ Lanjutkan`. Tombol itu wajib karena overlay
  (z-index 1080) menutupi bar kontrol (1050).
- Overlay hanya dirender saat `isPaused` dan `presState` masih `question-active` atau `time-warning`,
  jadi tidak menumpuk di atas overlay transisi.
- Perbaikan tambahan di jalur yang sama: `skipToNext` membersihkan `isPaused`. Sebelumnya pause lalu
  skip meninggalkan timer mati di soal berikutnya padahal layar terlihat normal.
- Bukti runtime: pause lewat Spasi menampilkan overlay lengkap dan glyph tombol berubah jadi ▶;
  klik "▶ Lanjutkan" menutup overlay dan timer jalan lagi (00:12); pause lalu klik tombol skip
  berpindah ke soal 02 dengan timer hidup (01:00 lalu 00:58) dan glyph kembali ⏸.

## Quick win yang dikerjakan

### Persistensi sesi (ide 1)
- Modul baru `src/storage.ts`: satu slot `quizboard.session.v1` berisi kuis, konfigurasi, posisi soal,
  dan penanda apakah guru sedang di presentasi. Akses dibungkus try/catch dengan probe tulis; kalau
  peramban memblokir storage, modul berhenti mencoba dan kuis tetap jalan tanpa persistensi. Data yang
  dibaca divalidasi per field (versi, bentuk soal, tipe tiap kunci config).
- Kartu "Lanjutkan kuis terakhir" di layar impor: nama kuis, posisi soal, umur simpanan, dan tiga aksi
  (Lanjutkan, Mulai dari awal, Lupakan).
- Keputusan timer yang disengaja: resume masuk ke soal terakhir dengan countdown dan timer soal yang
  baru, bukan melanjutkan sisa detik yang tersimpan. Tidak ada cara untuk tahu berapa lama tab tertutup,
  jadi melanjutkan detik yang tepat hanya akan jadi tebakan yang tampak presisi. Alasan ini ditulis di
  komentar kode.
- Bukti runtime: sesi tersimpan setelah impor demo (`version: 1`, mode, timer, posisi), kartu muncul
  setelah muat ulang dengan meta "IPA - Sistem Pernapasan Manusia · soal 2 dari 22 · disimpan beberapa
  detik lalu"; "Lanjutkan" membuka presentasi di soal 02 dari 22 dengan chip "Isian Singkat" dan timer
  60 detik; "Mulai dari awal" membuka layar setup dengan judul kuis dan 22 soal; "Lupakan" menghapus
  kartu dan kunci storage.

### Pengiriman tahap murah (ide 4)
- `vite.config.ts`: `base: './'`. Bukti: `dist/index.html` sekarang memuat `./assets/index-*.js` dan
  `./assets/index-*.css`, bukan path absolut. `dist` boleh diletakkan di subfolder mana pun.
- `run.bat`: kalau `dist\index.html` ada, jalankan `npm run preview` (port 4173) dan beri tahu cara
  membuka akses LAN dengan `--host`; kalau tidak ada, dev server seperti sebelumnya. Baris
  "students can open this on their phones" dihapus karena Vite tidak membuka LAN tanpa `--host`, jadi
  janji lamanya tidak benar.
- `README.md`: boilerplate Vite diganti README produk berbahasa Indonesia (cara menjalankan, memakai
  build di PC kelas, peringatan bahwa `file://` tidak bisa, format template, tombol dan shortcut,
  ringkasan struktur, penunjuk ke `DESIGN.md` dan audit).
- Belum diverifikasi di jalur ini: `run.bat` sendiri tidak dijalankan (butuh shell Windows baru), dan
  server `vite preview` tidak dinyalakan di sesi ini karena proses latar tidak tersedia di lingkungan
  ini. Yang terbukti adalah build menghasilkan `dist` dengan path relatif, dan script `preview` ada di
  `package.json`.

### Kunci jawaban cetak (ide 2)
- Komponen `AnswerKeySheet` dirender lewat `createPortal` ke `document.body`, dengan tabel nomor, tipe,
  jawaban, dan teks soal penuh dari `quiz.originalQuestions` (urutan asli, sama dengan panel 🔑).
  Header memuat judul kuis, jumlah soal, tanggal cetak dari `toLocaleDateString('id-ID')`, dan
  peringatan "Kunci jawaban. Jangan dibagikan ke siswa."
- `@media print` menyembunyikan `#root`, menampilkan lembar, dan mengembalikan `html/body/#root` ke
  `overflow: visible`; ada `@page { margin: 14mm }` dan `break-inside: avoid` per baris.
- Pemicu: tombol "🖨 Cetak Kunci Jawaban" di layar setup dan tombol "🖨 Cetak" di header panel 🔑.
- Bukti runtime: lembar ada sebagai anak langsung `BODY`, `display: none` di layar, berisi 22 baris,
  baris pertama `1 | PG | B. Paru-paru | Organ tubuh utama ...`. Aturan `@media print`, `@page`, dan
  `.print-sheet` terkonfirmasi ada di stylesheet yang dimuat.
- Belum diuji: hasil cetak di kertas. Tidak ada dialog cetak di lingkungan ini, jadi fungsi
  `window.print()` tidak dipicu. Dengan teks soal penuh, perkiraan saya 2 halaman untuk 22 soal; kalau
  terlalu panjang, opsi pertama adalah memotong teks soal di kolom terakhir.

## Temuan baru dari pekerjaan ini

### F-24 [R-19, C-4] Maskot berjalan di atas overlay (z-index 1500) - terbuka
- Maskot memakai `z-index: 1500`, di atas overlay pause (1080), dialog keluar (1150/1200), panel kunci
  jawaban (1200), dan preview (1300). Karena ketiga overlay itu kini benar-benar dirender, maskot akan
  melintas di atasnya selama presentasi.
- Dasar temuan ini adalah perbandingan z-index di `src/App.css`, bukan pengamatan visual: browser
  preview ini punya `prefers-reduced-motion: reduce`, dan pada mode itu aplikasi tidak merender maskot
  sama sekali. Jadi ini perlu diperiksa sekali di browser tanpa setelan tersebut.
- Ini memperkuat alasan F-06 ditutup, bukan alasan untuk menaikkan z-index overlay.

### F-25 [C-4] Favicon masih menunjuk berkas yang tidak ada - terbuka
- `index.html` memuat `/vite.svg` yang tidak ada di `public/` (404 di tab peramban), sementara
  `public/favicon.svg` dan `public/icons.svg` tidak dirujuk siapa pun.

### F-26 [C-1, R-20] Copy baru berbahasa Indonesia berdampingan dengan label Inggris - terbuka
- Tombol baru memakai bahasa Indonesia ("Cetak Kunci Jawaban", "Dijeda", "Lanjutkan kuis terakhir"),
  sementara judul panel dan overlay lama berbahasa Inggris ("Answer Key", "Next Question", "TIME'S UP",
  "Exit Presentation?"). Ini memperbesar masalah F-16, bukan menggantinya: voice belum diputuskan
  pemilik, jadi saya memilih konsisten dengan arah di `DESIGN.md` dan dengan fitur preview yang sudah
  berbahasa Indonesia.

### F-27 [di luar aturan UI, catatan operasional] Launcher lama menunjuk path yang tidak ada - terbuka
- `.freebuff/start.bat` berisi `cd /d "C:\Users\Admin\Documents\Quizboard\Freebuff"`, path dari mesin
  lain. Launcher itu akan langsung gagal. Tidak saya ubah karena berada di luar lingkup yang disetujui.

### F-28 [R-03 lanjutan] Font masih diambil dari Google Fonts - terbuka
- Pemuatan pertama butuh internet untuk Outfit, Plus Jakarta Sans, dan Space Mono. Sudah dicatat di
  README. Kalau aplikasi harus jalan penuh offline, font perlu di-host lokal, dan itu keputusan pemilik
  karena menambah aset ke repo.

## Delivery Gate untuk perubahan ini

### Block 1: Hard Gate
- Em dash di teks baru: **PASS**. `grep -rn "—" src/` kosong. Kemunculan di `DESIGN.md` adalah definisi
  larangannya, dan di dokumen audit adalah kutipan bukti.
- Overflow horizontal / layout mobile: **PASS** untuk yang diubah. Terukur di 440px: `clientWidth ===
  scrollWidth`, bar dua baris, label tersembunyi. Pada 360px dihitung: baris terlebar 212px. Desktop
  tidak berubah. Catatan: 360px tidak diukur di perangkat nyata.
- Statistik tanpa sumber: **PASS**. Tidak ada. Tanggal di lembar cetak berasal dari tanggal sistem.
- Testimoni fiktif: **PASS**. Tidak ada.
- Aset dibuat tanpa instruksi: **PASS**. Tidak ada aset, logo, atau avatar baru.
- Tautan navigasi ke halaman tidak ada: **PASS**. Tidak ada navbar.
- Kontras di bawah WCAG AA: **PASS** untuk pasangan yang diubah (7,2:1 dan 6,19:1). Kartu resume memakai
  `on-surface-variant` di atas `surface-container-low` (7,2:1). Sapuan penuh semua pasangan warna masih
  belum dilakukan, dan itu tetap tercatat sebagai keterbatasan.
- Kontrol mati: **PASS** untuk kontrol baru: "Lanjutkan dari soal" (klik nyata, masuk presentasi),
  "Mulai dari awal" (klik nyata, masuk setup), "Lupakan" (klik nyata, storage kosong), "▶ Lanjutkan" di
  overlay pause (klik nyata, timer jalan). Tombol cetak terverifikasi sebagai handler yang ada dan
  memanggil `window.print()`, tetapi tidak diklik di sesi ini karena membuka dialog cetak sistem, jadi
  jangan dibaca sebagai lulus penuh sampai ada yang mencetaknya.
- Keadaan UI (R-27): **PASS** untuk yang diubah. Keadaan "jeda" kini ada dan terlihat; keadaan kosong,
  sukses, dan error impor tidak berubah.
- FAQ generik: **N/A**. Tidak ada FAQ.
- Keyboard: **PASS**. Escape menutup lapisan teratas, fokus masuk ke dialog saat dibuka dan kembali ke
  tombol pembuka saat ditutup, `:focus-visible` tetap hidup.
- Patch script: **PASS**. Semua perubahan ditulis di source.
- Tema: **N/A**. Satu tema.
- Dijalankan dan diklik: **PASS** dengan daftar bukti di bagian status dan quick win di atas.
- Klaim keamanan, kepatuhan, performa: **PASS**. Tidak ada.
- Arah desain: **PASS**. `DESIGN.md` ada, dial eksplisit, dan copy baru mengikuti voice di dalamnya.

### Block 2: Purpose-Gate
- Animasi baru: **PASS**. Fade overlay pause dan denyut ikonnya menyatakan status, dan keduanya sudah
  dimatikan oleh kontrak `prefers-reduced-motion` yang ada.
- Blur: **PASS**. `backdrop-filter` hidup di tepat satu elemen (overlay pause), di dalam batas R-10.
- Ikon: **PASS**. ⏸ dan ▶ sama-sama menyatakan keadaan yang terlihat di tombol, bukan hiasan.
- Gradien, glow, badge, ilustrasi, shadow, kartu: tidak ada yang baru.

### Block 3: Liveliness
- Dial tetap `ENERGY 2 / RHYTHM 2 / MOTION 2` dan konsisten: layar pause adalah keadaan, bukan dekorasi,

  tombol cetak sejajar tombol preview.

  ada warna baru.

- R-15 (CTA generik): **PASS** untuk string baru ("Lanjutkan", "Mulai dari awal", "Lupakan", "Cetak
  Kunci Jawaban"). String lama yang generik tetap terbuka sebagai F-19.
- R-16 (buzzword): **PASS**. Tidak ada.
- R-29 (palet): **PASS**. Tidak ada warna baru, hanya token yang sudah ada.
